# Taghmesa Store

Static Arabic storefront for Taghmesa.

## Run locally

Open `index.html` directly in a browser, or serve the folder:

```sh
python3 -m http.server 8080
```

Then visit `http://localhost:8080`.

## Deploy

This repository is ready for static hosting providers such as GitHub Pages, Netlify, or Vercel. Use the repository root as the publish directory; `index.html` is the entry file.
